# screening

120,000 candidate compositions, 480,000 surrogate states, applicability filters, Pareto outputs and direct confirmation.

These are the actual archived stage sources. Run them through `src/reproduce.py prepare` and `run` so their historical paths resolve in a separate workspace. Paired inputs and saved outputs are indexed under `data/screening/`. Data are not modified in the release. Training and thermodynamic stages can be expensive.
