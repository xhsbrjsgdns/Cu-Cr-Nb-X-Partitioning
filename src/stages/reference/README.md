# reference

50,000 compositions, 550,000 attempted equilibrium states, raw phase instances, conserved elemental partition vectors and failure records.

These are the actual archived stage sources. Run them through `src/reproduce.py prepare` and `run` so their historical paths resolve in a separate workspace. Paired inputs and saved outputs are indexed under `data/reference/`. Data are not modified in the release. Training and thermodynamic stages can be expensive.
