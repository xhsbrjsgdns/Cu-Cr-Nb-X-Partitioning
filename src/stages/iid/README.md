# iid

Candidate descriptors, selected features, composition splits, tuning records, IID prediction/reference pairs and final estimators.

These are the actual archived stage sources. Run them through `src/reproduce.py prepare` and `run` so their historical paths resolve in a separate workspace. Paired inputs and saved outputs are indexed under `data/iid/`. Data are not modified in the release. Training and thermodynamic stages can be expensive.
