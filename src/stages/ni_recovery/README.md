# ni_recovery

Anchor sequences and fixed evaluation population; model refits, R0/R1/R2 controls, per-state predictions and checkpoint/history files.

These are the actual archived stage sources. Run them through `src/reproduce.py prepare` and `run` so their historical paths resolve in a separate workspace. Paired inputs and saved outputs are indexed under `data/ni_recovery/`. Data are not modified in the release. Training and thermodynamic stages can be expensive.
