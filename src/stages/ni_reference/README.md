# ni_reference

22,000 Ni reference states, raw phases, target vectors, failure/solver records and blind-test scoring.

These are the actual archived stage sources. Run them through `src/reproduce.py prepare` and `run` so their historical paths resolve in a separate workspace. Paired inputs and saved outputs are indexed under `data/ni_reference/`. Data are not modified in the release. Training and thermodynamic stages can be expensive.
