# element_ood

Six held-out-element tasks with per-state predictions, true labels, fold-specific features and selected model settings.

These are the actual archived stage sources. Run them through `src/reproduce.py prepare` and `run` so their historical paths resolve in a separate workspace. Paired inputs and saved outputs are indexed under `data/element_ood/`. Data are not modified in the release. Training and thermodynamic stages can be expensive.
