# Data and Software Availability

The data supporting this study, including alloy compositions, CALPHAD reference outputs, descriptor values, fixed data splits, prediction outputs, Ni anchor sequences, literature-comparison tables, and figure source data, are available in the Supporting Information and in the `data` directory at https://github.com/xhsbrjsgdns/Cu-Cr-Nb-X-Partitioning (release v1.0.0). The scripts used for thermodynamic data processing, model development and evaluation, and statistical analysis are available in the `src` directory of the same repository, together with environment specifications and reproduction instructions. The Thermo-Calc software and TCCU6 thermodynamic database are commercial products and are not redistributed; rerunning the equilibrium calculations requires the corresponding licenses. The deposited reference outputs enable the machine-learning evaluation and numerical analyses to be reproduced without access to the commercial database.
